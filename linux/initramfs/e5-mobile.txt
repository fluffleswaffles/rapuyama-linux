3G mobile data on the Nokia E5 (Linux, advanced setup)

1. Once: in Linux (LinuxE5 or 3GLinuxE5), as root, run
     mobile setup
   It asks for the phone's IMEI (dial *#06# in Symbian, 15
   digits) and your operator's APN (look it up on the
   operator's site, e.g. "internet"), checks the IMEI and saves
   both on the memory card (E:\linux\e5-imei, E:\linux\e5-apn).
   Linux never reads them from Symbian, never shows the IMEI.
   Change the APN later: mobile apn <name>
2. In Symbian's settings allow 3G (network mode Dual mode or
   UMTS) and high speed packet access (HSDPA) for fast data.
3. Start Linux with 3GLinuxE5 (LinuxE5 = Wi-Fi only, no modem).
   Data comes up by itself within ~2 minutes.

   mobile        status: modem, network, data, APN, bytes
   mobile on     data on (after mobile off)
   mobile off    data off; the modem keeps running

Wi-Fi wins when both are up (its route and DNS are kept). If
Wi-Fi goes away while data is on, names stop resolving: run
mobile off, then mobile on.
"modem stopped" = the modem runtime ended: reboot (it runs once
per boot and must start within 90 s of boot).
3G uses the battery faster; Linux does not charge the phone yet.
